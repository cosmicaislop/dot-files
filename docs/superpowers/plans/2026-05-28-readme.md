# README + Install Script Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a README.md and a `run_once_install-deps.sh.tmpl` so the repo is self-bootstrapping on a fresh machine.

**Architecture:** Two files at the repo root. The install script uses chezmoi's `.work` template variable to branch between macOS (brew) and Linux (dnf + flatpak). The README documents what's managed and how to set up a new machine end-to-end.

**Tech Stack:** chezmoi (Go templates), bash, brew (macOS), dnf + flatpak (Fedora Linux)

- [ ] **Step 1: Write the script**

Create `/Users/ndayal/.local/share/chezmoi/run_once_install-deps.sh.tmpl` with:

```bash
#!/bin/bash
set -e
{{ if .work -}}
brew install neovim tmux starship
brew install --cask ghostty alacritty
{{- else -}}
sudo dnf install -y neovim tmux alacritty
sh -c "$(curl -sS https://starship.rs/install.sh)" -- --yes
flatpak install -y flathub com.mitchellh.ghostty
{{- end }}
```

# dotfiles

Managed with [chezmoi](https://chezmoi.io).

## What's managed

- zsh + aliases
- neovim
- tmux
- ghostty
- alacritty
- starship
- git
- gnome settings and themes (Linux only)

## Prerequisites

Install chezmoi:

\```sh
sh -c "$(curl -fsLS get.chezmoi.io)"
\```

## Quick start

\```sh
chezmoi init --apply git@github.com:cosmicaislop/dot-files.git
\```

You'll be prompted: **Is this a work machine?**
- `y` — macOS; gnome files are skipped
- `n` — Linux; full setup including gnome theme restore

Dependencies (neovim, tmux, starship, ghostty, alacritty) are installed automatically via `run_once_install-deps.sh`.

## Platform notes

**macOS:** gnome configs and the themes directory are excluded via `.chezmoiignore`.

**Linux (Fedora):** `restore-gnome-settings.sh` runs once on first apply to re-enable extensions and set the shell theme.
```
